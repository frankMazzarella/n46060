# N46060 Weight & Balance

Single-page weight and balance calculator for N46060, a 1968 Cessna 172I.

Empty weight and moment are from the airplane's weighed record. Station arms and the normal and utility envelopes were read off the handbook loading graph and CG moment envelope, so they are approximate. Planning aid only; the pilot in command owns the final calculation.

No build step. Open `index.html` or serve the folder with any static host.
